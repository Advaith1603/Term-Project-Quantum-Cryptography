# 🔐 Crypto Project — Miller–Rabin & Shor Benchmark

This repository contains a Jupyter Notebook focused on comparing:

- **Miller–Rabin Primality Test** (probabilistic + deterministic version)
- **Small-N Shor’s Algorithm** implementation using Qiskit

The goal is to benchmark **runtime** and **accuracy** for both classical and quantum-inspired techniques used in cryptography.

---

## 📌 Features

✔ Miller–Rabin primality test implementation  
✔ Deterministic MR for accurate validation up to 64-bit numbers  
✔ Benchmark based on different bit lengths  
✔ Small-number Shor’s algorithm using Qiskit  
✔ Factoring success rate + runtime comparison  
✔ Publication-style plots for results visualization
